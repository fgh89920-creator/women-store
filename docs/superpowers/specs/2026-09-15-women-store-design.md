# وثيقة تصميم — متجر إلكتروني نسائي

**التاريخ:** 2026-09-15
**الحالة:** مسودة للمراجعة
**المشروع:** متجر إلكتروني متخصص بمنتجات النساء

---

## 1. نظرة عامة

متجر إلكتروني **للنساء فقط** بأسلوب شي إن (Shein): كتالوج منتجات غنية، حركات دقيقة، وتجربة تصفح جذابة. الزبونة تتصفح، تضيف للسلة، وتطلب بدون تسجيل حساب (التسجيل اختياري).

---

## 2. الجمهور المستهدف

| البند | التفصيل |
|---|---|
| **الفئة** | نساء |
| **الفئة العمرية** | 16–45 |
| **المنطقة** | العالم العربي (الأسواق الناطقة بالعربية) |
| **اللغة** | عربي فقط (RTL) |

---

## 3. النطاق (Scope)

### داخل النطاق ✅
- عرض المنتجات بصرياً مع حركات احترافية
- سلة شراء + عملية طلب (Checkout)
- لوحة تحكم للإدارة (Admin) لاستقبال وإدارة الطلبات
- لوحة تحكم للإدارة لإدارة المنتجات والأقسام
- تسجيل دخول اختياري (الزبونة تقدر تطلب كضيف)
- بحث وفلترة المنتجات
- موقع RTL كامل

### خارج النطاق ❌
- **لا يوجد دفع إلكتروني حقيقي** (الدفع عند الاستلام فقط)
- لا يوجد تطبيق جوال منفصل (responsive web بدلاً من ذلك)
- لا توجد مراجعات/تقييمات من الزبائن (قد تُضاف لاحقاً)
- لا توجد محادثة مباشرة (chat) مع الزبائن
- لا يوجد نظام كوبونات/خصومات (قد يُضاف لاحقاً)

---

## 4. الأقسام (Categories)

الموقع يدعم **الأقسام الأربعة** كلها:

1. 💄 **مكياج وأدوات تجميل** (أحمر شفاه، كحل، بودرة، فرش، إسفنجات)
2. 🧴 **العناية بالبشرة والجسم** (كريمات، سيروم، ماسكات، عطور)
3. 💍 **إكسسوارات ومجوهرات** (حلق، عقود، أساور، خواتم)
4. 👗 **ملابس نسائية** (فساتين، بلوزات، تنانير)

## 7. نموذج البيانات (Data Model)

### 7.1 المنتج (Product)

```
{
  _id: ObjectId,
  name: string (عربي),
  slug: string (URL-friendly),
  description: string (عربي),
  price: number (ريال سعودي — قابل للتعديل لاحقاً),
  images: string[] (URLs للصور),
  category: ObjectId (مرجع للقسم),
  stock: number (الكمية المتاحة),
  isNew: boolean (منتج جديد؟),
  isFeatured: boolean (مميز بالرئيسية؟),
  createdAt: Date,
  updatedAt: Date
}
```

### 7.2 القسم (Category)

```
{
  _id: ObjectId,
  name: string (عربي),
  slug: string,
  description?: string,
  image?: string (صورة للقسم)
}
```

### 7.3 الطلب (Order)

```
{
  _id: ObjectId,
  orderNumber: string (للعرض للإدارة),
  customer: {
    name: string,
    phone: string,
    address: string,
    city: string,
    notes?: string
  },
  items: [
    { productId, name, price, quantity, image }
  ],
  total: number,
  status: 'new' | 'processing' | 'shipped' | 'delivered' | 'cancelled',
  userId?: ObjectId (إن وُجد حساب),
  createdAt: Date
}
```

### 7.4 المستخدم (User) — اختياري

```
{
  _id: ObjectId,
  name: string,
  email: string (unique),
  password: string (hashed),
  phone?: string,
  addresses: Address[],
  favoriteProducts: ObjectId[],
  orders: ObjectId[],
  createdAt: Date
}
```

## 8. متطلبات غير وظيفية

| البند | الهدف |
|---|---|
| **الأداء** | أول ظهور (LCP) < 2.5 ثانية |
| **الاستجابة** | الموقع يشتغل على موبايل + تابلت + ديسكتوب |
| **إمكانية الوصول** | ألوان بتباين كافي، أزرار بحدود واضحة |
| **الـ SEO** | كل منتج عنده meta title و description بالعربي |
| **الأمان** | HTTPS، تشفير كلمات السر، تحقق من المدخلات |
| **الحركات** | Framer Motion، مدتها 200-500ms، تستخدم spring |

## 9. تدفق العمل

```
الزبونة تتصفح
   ↓
تنقر على منتج
   ↓
تضغط "أضيفي للسلة"
   ↓
تذهب لـ /cart
   ↓
تكتب بياناتها (بدون تسجيل)
   ↓
تضغط "تأكيد الطلب"
   ↓
الطلب ينخزن بقاعدة البيانات
   ↓
الإدارة تشوفه على /admin
   ↓
الإدارة تحدّث الحالة (جديد → قيد التجهيز → شُحن → تم)
```
